# Hisaab

A mobile-first universal digital ledger for individuals and businesses.

## Vision

Hisaab helps users manage financial relationships, track money owed and payable, record transactions, manage projects and generate financial statements.

## Technology Stack

- Frontend: React + Vite
- UI: Material UI
- Icons: Lucide React
- Backend: Supabase
- Database: PostgreSQL
- Mobile: Progressive Web App (PWA)

## Project Structure

- `apps/web` - Frontend application
- `supabase` - Backend and database
- `docs` - Product and technical documentation
- `scripts` - Development scripts

## Development Approach

1. GitHub and project setup
2. Supabase configuration
3. Backend and database development
4. Frontend development
5. Testing and deployment

## Important

Financial records must be accurate, secure and auditable.

Never commit passwords, API secrets or private credentials.
